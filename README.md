# 知金台 · 每日金融工作台

静态站点，包含金融基础知识卡、搜索、本机收藏和金融简报。

## 搜索与知识补充
首页新增问题搜索，匹配现有概念及本期简报，同时补充相关生活类比、原理与误区。
GPT 搜索已改为本机 Plus 版，代码位于 `local-plus/`。双击 `启动知金台.cmd`，通过官方 Continue with ChatGPT 登录并授权套餐使用，然后在 `http://127.0.0.1:18741/` 搜索。电脑和本机服务需要保持运行；不需要填写 API 密钥或搜索访问码。用量与模型以账号实际权限为准。
公网首页保留站内搜索，并提供“打开本机 Plus 版”入口。原 `backend/` API-key 后端保留为备用代码，当前公开配置不再调用它。

## 每日更新
在 site/briefs/YYYY-MM-DD.html 保存已核验的简报，并更新 site/index.html 的 latest-brief 区域及内容日期；运行 `node scripts/build-knowledge.mjs` 后，连同生成的 site/daily-knowledge.js 一起提交。热点速览与学习卡自动跟随当前简报；每天北京时间09:00后还没有当期内容会显示待更新提示。提交会部署网站，但不会自动生成新闻，也不会发送邮件。
每日内容生成与邮件发送由原定时任务承担，已切换到本仓库和新网址，按北京时间每天 09:00 开始处理。网站本身不保存收件人或邮件凭据。

## 隐私
页面发布后公开可访问。此迁移包不含邮件地址、发送记录、凭据、原站项目配置或 Git 历史。
收藏和表单偏好仅保存在访客自己的浏览器。换域名后原站收藏不会自动转移。
